## 구조
- `_posts/` — 글. 파일 이름은 `YYYY-MM-DD-영문-제목.md`
- 글 머리말(front matter)의 `lang` (ko / zh / en)으로 언어별 목록에 나뉘어 보임
- `social.facebook` — 페이스북·인스타용 짧은 글 (자동 게시에 사용 예정)
- `_layouts/`, `assets/style.css` — 디자인
